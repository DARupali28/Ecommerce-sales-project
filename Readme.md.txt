# Sales Analysis & MIS Dashboard – Excel

## 📊 Project Overview

This project is an **Excel-based Sales Data Analysis and MIS Dashboard** created to analyze sales performance, product performance, stores, salespersons, customer types, and regional performance.

The project includes raw sales data, an MIS report, and an interactive dashboard in a single Excel workbook.

## 📁 Project Structure

The Excel workbook contains three main sheets:

### 1. Data

Contains **1,500 sales records** and 24 columns, including:

* Year
* Month
* Date
* Region
* Product
* Quantity
* Unit Price
* Store Location
* Customer Type
* Discount
* Salesperson
* Total Price
* Payment Method
* Promotion
* Returned
* Order ID
* Customer Name
* Shipping Cost
* Order Date
* Delivery Date
* Region Manager
* Raw Total Price
* Discount Price

### 2. MIS Report

The MIS Report summarizes important business metrics such as:

* Total Sales
* Sales by Store
* Sales by Salesperson
* Sales by Customer Type
* Sales by Product
* Quantity by Product
* Sales by Year
* Sales by Region Manager
* Product sales performance

The report uses Excel summary tables to make the sales data easier to analyze and understand.

### 3. Dashboard

The Dashboard provides a visual representation of the sales analysis and helps users understand the overall business performance through charts and summarized information.

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze overall sales performance
* Compare sales across different stores
* Analyze product-wise sales and quantity
* Compare salesperson performance
* Analyze Retail vs Wholesale customers
* Analyze yearly sales trends
* Understand regional performance
* Create an MIS report for business reporting
* Build an Excel dashboard for visual analysis
